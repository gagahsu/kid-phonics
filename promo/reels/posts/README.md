貼文：打開 txt 全選複製，直接貼到 IG。QR code：`out/qr-kid-phonics-cats.png`（`npm run qr` 重做）。
`out/` 不進版控，影片、封面要重新產生：`npm run render`、`render2`、`render3`，
封面 `npx remotion still Reel out/cover-1.png --frame=290`（Reel2 `--frame=110`、Reel3 `--frame=95`）。

## 發布前

- 個人簡介放網址 `https://gagahsu.github.io/kid-phonics/`，加一句「給 5–7 歲孩子的注音練習」。
- 確認 3 支都用相同的帳號名稱、頭像；簡介連結是 Reels 觀眾唯一能點的地方。
- 試一次：手機打開網站，圖卡聲音、遊戲都正常。

## 順序和時間

1. **第 1 支（總覽）先發**：問題開場，最容易讓沒看過的人停下來，也把網站整體交代清楚。
2. **隔 2–3 天發第 2 支（胖胖）**：角色和遊戲最有趣，適合有人看過第 1 支後接著看。
3. **再隔 2–3 天發第 3 支（安心）**：說服家長放心給孩子用，接在前兩支之後收尾。

時間挑家長有空滑手機的時段，例如孩子睡後的晚上 9 點前後，或週末早上；3 支盡量同一個時段發，方便比較成效。

## 每支發布當天

- **封面**：發 Reels 時「編輯封面」→ 從相機膠卷選對應的 `cover-*.png`。
- **分享到限時動態**：Reels 發出後分享到限動，加「連結」貼紙放網址；限動的連結貼紙是 IG 上少數點得到的連結。
- **精選動態**：限動收進精選「發音樂園」，之後新訪客也找得到。
- **置頂**：3 支都發完後，把 3 支置頂在個人檔案（IG 可以置頂 3 則）。
- **留言**：第一則留言可以自己補充，例如「想要網址的留言『注音』，私訊傳給你」；私訊裡的網址點得到。
- **hashtag**：IG 從 2025 年底起每則最多 5 個（說明文字和留言合計），貼文裡已經各放 5 個，不要再加。

## 其他平台

- 同一支影片可以發 Facebook Reels、Threads、YouTube Shorts（都支援 9:16、60 秒內）。
  YouTube Shorts 和 Facebook 貼文的網址可以點，效果可能比 IG 好。
- LINE 家長群組、幼兒園群組：直接傳影片，QR code 和網址都在片尾。

## 發完之後看什麼

- **觀看完成率**：前 3 秒有沒有留住人（開頭是不是太慢）。
- **分享、收藏**：家長覺得有用才會轉傳；這兩個數字比按讚重要。
- **個人檔案瀏覽、連結點擊**：有沒有真的導到網站。
- 哪一支表現最好，下一批就照那支的開場方式做。

## 注意

- 第 1 支用了教育部錄音（CC BY 4.0），貼文最後的出處那行不要刪。
- 家長頁、月曆、獎狀、我的聲音都是示範資料，影片和貼文都已註明。
- ABC、あいう 還在準備中，不要寫成已經有。
- 背景音樂是自己合成的（`scripts/bgm.py`），沒有版權問題；IG 會顯示為「原創音訊」。
